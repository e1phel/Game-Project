# Manor - Unreal Engine 5 Project

A simple, small semester project. A Soulsborne-inspired mini game built in Unreal Engine 5 as part of 
My game development studies.

## What is Manor?
Manor is a Souls-Lite Game. You enter the Manor intending to retrieve the Manor Records. You have to fight and avoid enemies, explore new pathways, and find the Manor records.
